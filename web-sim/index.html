🎯 51 MCU 机器运动模拟器

以浏览器交互演示 STC89C52 项目中的 UART 协议、 LED 点阵扫描和烧录编程的工作流程。

⚙️ 模拟功能

  • 10 字节帧协议解码 · 帧头 0xAA + XOR 校验
  • UART 逐字节接收状态机 · 9600-8N1
  • 8×8 LED 点阵 · T0 定时器逐行动态扫描（2ms）
  • 环形队列缓冲 · 32 帧容量
  • ACK 应答 · 0xCC + 序号
  • 急停中断 · INT0 (P3.2) 下降沿触发
  • 安全停机 · 停止定时器 + LED 全灭 + 死循环
  • STC-ISP 冷启动烧录模拟

🔀 数据流

MATLAB → trajectory.txt → PC 控制层 → 串口 (COM3)
   ↳ 51 MCU (UART RX) → protocol_decode → queue
      ↳ led_plot_point → 8×8 LED 矩阵 ← T0 中断扫描
